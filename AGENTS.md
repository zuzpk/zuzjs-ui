# Zuz UI Agent Rules

Read and follow `AI_SKILL.md` before generating UI with this package.

## Required

- Use only exported components from `@zuzjs/ui`.
- Resolve props from each component `types.ts` file.
- Use `as` utility syntax and shortcuts from this package source.
- Do not invent props, shortcuts, breakpoints, or variants.
